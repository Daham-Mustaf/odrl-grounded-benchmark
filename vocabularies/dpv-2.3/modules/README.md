# DPV 2.3 modules

Files taken from the 2.3 release of the Data Privacy Vocabulary
(https://w3id.org/dpv/2.3). `consent_status.ttl` is the file of the DPV
repository at `2.3/dpv/modules/consent_status.ttl` (last changed there by
commit `5af893701677a4a54a28ad617e350bb98cf4d3b8`, 20 February 2026); it
carries `owl:versionInfo "2.3"`. An earlier copy in this folder was the 2.0
file and carried `owl:versionInfo "2.0"`. Rebuilt from the 2.3 file, the
consent resource and its declarations differ from the 2.0 build in two header
lines only, the version and the retrieval date: the same 13 concepts, the same
12 order statements.
